# **App Name**: Annadata AI

## Core Features:

- Crop Disease Diagnosis: Diagnose crop diseases by analyzing images using the Gemini model, providing treatment advice. This model is used as a tool.
- Real-Time Market Analysis: Fetch real-time market data, analyze trends using the Gemini model, and provide actionable insights. The AI model decides what information is important as a tool to display to the user.
- Government Scheme Navigator: Explain government agricultural schemes based on user needs, providing eligibility details and application links; Gemini model used as tool to understand the information need of the farmer.
- Voice-First Interaction: Enable voice interaction using Speech-to-Text and Text-to-Speech for easy communication.
- Multilingual Support: Provide support for multiple local languages.
- Information Display: Display remedies, market prices, and scheme details in simple, easy-to-understand formats.

## Style Guidelines:

- Primary color: Earthy green (#6B8E23) to evoke nature and growth.
- Background color: Light beige (#F5F5DC) to provide a neutral and calming backdrop.
- Accent color: Warm yellow (#FFC72C) to highlight important information and calls to action. This provides a strong contrast and represents optimism and sunlight.
- Body and headline font: 'PT Sans' (sans-serif) to provide clarity and readability.
- Use clear, universally understandable icons representing crops, markets, and government services.
- A clean, intuitive layout with a focus on accessibility, ensuring easy navigation for users of all literacy levels.
