# Annadata AI

An AI-powered personal assistant designed to empower farmers with technology.

## What Can Annadata AI Do For You?

Annadata AI provides farmers with instant, reliable, and actionable information through several powerful features:

### 🌱 Crop Disease Diagnosis
- Take or upload photos of your crops to get instant AI-powered disease diagnosis
- Receive detailed treatment and remedy recommendations
- Get preventive measures to protect your crops
- Support for multiple crop types

### 📈 Real-Time Market Analysis
- Access up-to-date market prices for various crops
- Get AI-powered market trend analysis and predictions
- Receive recommendations on the best time to sell
- Compare prices across different markets
- Get actionable insights for maximizing profits

### 🏛️ Government Scheme Navigator
- Discover government agricultural schemes tailored to your needs
- Understand eligibility criteria and requirements
- Get step-by-step application guidance
- Access direct links to official application portals
- Learn about available subsidies and financial assistance

### 🎤 Voice-First Interaction
- Speak your queries instead of typing
- Listen to AI responses with text-to-speech
- Perfect for users of all literacy levels
- Convenient hands-free operation while working in the field

### 🌍 Multilingual Support
- Use the app in your preferred language
- Support for multiple Indian languages
- Clear and simple explanations
- Culturally relevant recommendations

## Getting Started

To get started with development:

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:9002`

## Tech Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS
- Genkit AI
- Radix UI Components
